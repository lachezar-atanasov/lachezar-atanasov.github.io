Cabrevo

A night-time landing page for a fictional electric taxi, built around one interaction.

Independent concept project. Not a real company. Not client work. Source code available on request.

Open the live demo

The brief

Small businesses often ask for a landing page that feels premium and does one thing well. I set myself that brief for an invented taxi brand: make the page memorable, and make its one feature something you want to try.

What I built

A single page with a hero, a route explorer, how a ride would work, the fleet, hours and districts, questions and a closing call to action.

  • A route explorer: pick a pickup and a drop-off, and the route draws itself along roads and bridges
  • Shortest-path routing over a small road graph, with a sample fare, time and distance
  • Empty, one-stop and result states, swap and reset, and shareable links
  • On phones the map comes first and the result sticks to the bottom of the screen
  • Original SVG map and vehicle drawings, with no images, map service or tracking

How it was made

I explored three art directions with Lovable: a cinematic night look, a transit-signage system and an editorial print style. I compared them at desktop and phone widths and chose the night look, because its glowing route made the one interaction the hero of the page.

I then brought that code into my own repo and rebuilt and finished the page with AI coding tools: the road routing, the city map, the remaining sections, URL state, tests, accessibility and performance work.

Three decisions

Honest by design. The page says it is a concept next to the main call to action and in the footer, and every figure is labelled "Sample".

Routes follow roads. A straight line between two dots looks fake, so routes take the shortest path over the city's roads and cross the river by a bridge.

The keyboard gets the same feature. The map is for mouse and touch; the district list next to it does the same job by keyboard, and a screen reader hears each result.

Testing

8 automated tests cover fares, routing and shared links. I checked the production build in a browser at 320, 375, 768, 1024, 1440 and 1920 px, with touch emulation and with the keyboard. Lighthouse on the local production build scored 100 for performance, accessibility, best practices and SEO, on mobile and desktop.

What I'd improve

Keyboard focus on the map dots themselves, a light theme, and a real booking flow if this were ever a real product.
