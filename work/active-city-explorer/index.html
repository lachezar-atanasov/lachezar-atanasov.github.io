Active City Explorer

An interactive React dashboard for finding what is open, where and when.

Independent concept project. All data fictional. Not client work.

Open the live demoView the source

The problem

Location data is hard to use as a long list. People want one quick answer: what can I do near me, at the time I want to go?

What I built

A responsive dashboard for 420 generated venues. A time slider moves through any hour of any day, and the map, stats and charts update together.

  • A custom SVG map with dots, density cells, drag and zoom
  • Search, activity chips, plan and open-only filters
  • A side panel on desktop and a bottom sheet on phones
  • Filters and selection saved in the URL, so any view can be shared
  • Light and dark themes

Three decisions

Unknown stays unknown. Missing hours show as "Hours unknown", never as closed. Each state has its own symbol, so meaning doesn't depend on colour.

No map service. The map is plain SVG, so there are no API keys or usage costs.

Links that can't break the page. Invalid URL values fall back to safe defaults.

Testing

15 automated tests cover opening hours, filters, shared-link state and map binning. I also checked the production build in a browser at phone, tablet and desktop widths.

What I'd improve

Real user location, keyboard navigation between map dots, and a real data source that allows this use.
